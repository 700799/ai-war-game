# SIGNAL / NOISE — Superintelligence Wargame

A think-tank-style, game-theoretic superintelligence wargame in a pixel/Nintendo UI. Eight rounds against a rival state, while profit-driven labs, the open-source commons, criminal syndicates and Congress play their own games.

**Play:** https://700799.github.io/ai-war-game/

Single static file (`index.html`), served by GitHub Pages from `main`.

Fictional scenario. Actors are archetypes, not real organizations.
